# Customize command: one panel for the three toggles
Replace `/herdr-gentle:sidebar`, `/herdr-gentle:moshi` and `/herdr-gentle:worktree` with a single `/herdr-gentle:customize` panel that shows all three switches with a one-line description each, applies the chosen change immediately, and reloads the extension runtime only when the change cannot take effect without it. A separate `/herdr-gentle:warp` command offers the project's checkouts as a selector and moves the session to the chosen one.
